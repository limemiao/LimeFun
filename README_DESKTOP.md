# LimeFun 桌面版

桌面版使用 Windows WebView2 创建独立应用窗口，复用 LimeFun 网页端的完整功能：番剧搜索与筛选、播放列表、选集播放、倍速播放、下载中心、下载进度、下载记录和失败重试。不会打开带地址栏的浏览器窗口。

## 启动

桌面版需要先用 `build.cmd` 构建（会生成到 `runtime/current/`），然后运行：

```text
runtime\current\LimeFunWebView\LimeFunWebView.exe
```

也可以直接双击 `启动LimeFun桌面版.bat`。程序启动时会自动检查并启动本地后台服务 `127.0.0.1:8765`。后台服务使用隐藏窗口运行，不会弹出 Terminal；关闭桌面窗口后，由本次启动的服务进程自动退出。

## 要求

- Windows 10/11。
- 系统已安装 Microsoft Edge WebView2 Runtime。
- 数据目录为 `D:\Anime`、`D:\NewAnime`，远程清单和下载状态保存在项目目录。

如果 8765 端口已被其他程序占用，请先关闭占用该端口的程序。

## 删除下载任务与记录

- 当前任务支持单条删除、勾选多条和全选后批量删除。下载中的任务会先停止，再清理对应 `.part` 临时文件；完整视频保留。
- 下载记录支持单条与批量删除。使用搜索后，“全选搜索结果”只选择当前匹配记录；更改搜索词会清空选择。
- 自动刷新保留勾选。删除前会显示确认框，失败项目会保留并显示原因；临时文件清理失败时可点击“重试删除”。
- “正在删除”表示后台尚在退出网络请求或清理文件。重启会继续处理尚未完成的删除，不会将这些任务重新加入下载队列。
- 删除任务和删除历史记录分别操作。删除历史记录不会停止当前下载，也不会删除视频。

## 播放界面

播放页采用主视频区与右侧栏布局。右侧可切换“选集”和“播放列表”，支持按集数或名称搜索，以及定位当前集；完整文件名与大小可在集数按钮上悬停查看。

桌面宽屏模式收起侧栏并扩大视频，切换时保持当前播放。手机端按视频、播放控制、选集的顺序排列。自动连播可关闭，倍速设置会在换集时保留。

播放界面的更新由桌面版与 Web 版共用，刷新播放页或重新打开桌面窗口即可加载。
