# LimeFun 本地番剧查看、搜索与播放

这是一个只在本机运行的 Web 应用，用浏览器读取本地媒体库，不需要把视频上传到网络，也不需要 MuteFun App。应用分为查看/搜索页、播放页和下载中心。

## 启动

在 `limefun` 中运行：

```powershell
cd limefun
python -m limefun.player_server
```

然后打开 <http://127.0.0.1:8765>。根路径是查看/搜索页，播放页是 <http://127.0.0.1:8765/player.html>，下载中心是 <http://127.0.0.1:8765/downloads.html>。

如果端口被占用，可以换一个端口：

```powershell
python -m limefun.player_server --port 8766
```

也可以指定媒体库路径：

```powershell
python -m limefun.player_server --archive "D:\Anime" --new "D:\NewAnime"
```

## 查看/搜索页

根路径 `/`（也可以直接打开 `/browse.html`）读取 `mutefun_catalog_full.json`，筛选字段来自清单本身：

- 名称或 ID：匹配 `vod_name` 和 `id`
- 首播年份：优先使用已匹配的正式首播年；季度未知的作品回退到详情接口补全的 `vod_year`
- 首播季度：1–3 月 / 4–6 月 / 7–9 月 / 10–12 月，可单独筛选“季度未知”
- 类别：拆分 `vod_class` 的逗号分隔值
- 本地文件：根据 `D:\Anime` / `D:\Anime` 的实际文件匹配结果
- 本地独有系列：不在 MuteFun 清单中的本地系列自动归入“其他”，仍可搜索和播放
- 状态：匹配 `vod_isend`
- 排序：名称、首播年、ID

结果卡片显示 `vod_pic` 的本地封面、`vod_remarks`、类别标签、首播季度和本地集数。只有本地已有视频的结果可以直接打开播放页；带有在线清单的结果可以点击“加入下载”，本地已有的番剧也可以点击“更新下载”补齐缺失集数。点击后会先选择具体集数，已下载、下载中、未下载和失败状态会分别显示；失败集数再次勾选时会执行续传重试。服务启动后会在后台定期同步远程清单，页面也提供“同步远程清单”按钮。

### 下载目录规则

下载和“更新下载”按以下规则创建或选择目录：

- 基础目录始终使用番剧名，不带季/剧场版后缀。
- 第二季/第三季/第2部分 → `番剧名/第二季`、`番剧名/第2部分`。
- 剧场版 → `番剧名/剧场版 <副标题>`，例如 `链锯人/剧场版 蕾塞篇`。
- OVA/OAD/SP/特别篇/总集篇/合集 → `番剧名/OVA`、`番剧名/特别篇` 等。
- 第一季：基础目录不存在时直接使用基础目录；基础目录已有平铺视频时写入基础目录；已有 `第一季`、`正片` 等子目录时复用该子目录。
- 如果同一个完整标题已经有目录（例如 `进击的巨人/进击的巨人 第三季`），直接复用，避免把同一季拆到两个目录。
- 如果完整标题已经有一个顶层目录（例如历史遗留的 `石纪元 第四季 第3部分`），也会复用该目录，不会自动搬家；需要统一到 `番剧名/后缀` 结构时，可另行整理这些历史顶层目录。

首播资料保存在 `limefun/player_web/season-data.json`，由 `bangumi-data`（CC BY 4.0）的离线快照与人工核对的公开 Bangumi 条目生成。页面只读取这个文件，不会联网查询或随远程清单同步改写；目前 2,203 条中已确认 2,142 条，其余 61 条显示“季度未知”。季度按作品在原播出地的正式首播月份归类，跨季连载归入首播季度，剧场版和 OVA 也按首映/首播日期归类。重新生成方法见 `tools/lime-ui-refresh/README.md`。

## 播放页

`/player.html` 负责读取本地视频，支持系列、季/目录、选集、上一集、下一集和播放结束自动跳集。播放列表默认为空；从查看页打开本地番剧时才会加入播放列表，列表中的项目可以手动删除。查看页的“打开播放页”会把番剧名称传给播放页，自动定位到对应本地系列。

## 下载中心

`/downloads.html` 显示下载队列的实时状态和下载记录。任务在后台执行，进度按已下载字节更新；网络错误或服务重启导致的中断会标记为失败，并可直接点击“重试”。下载使用 `.part` 临时文件和 HTTP Range 续传，成功后才替换为正式视频文件。

下载记录只由查看页点击“加入下载”或“更新下载”创建的任务写入。启动前已经存在于 `D:\Anime` / `D:\Anime` 的视频只会在目录索引中显示，不会自动出现在下载记录中。

## 界面和本地视频索引

- 左侧切换“番剧”和“新番”媒体库。
- 搜索框按系列名称过滤。
- 选中系列后，可在“季 / 目录”下拉框中选择子目录。
- 集数按钮会显示文件名和文件大小，点击即可播放。
- “上一集”“下一集”支持手动切换，视频播放结束后会自动进入下一集。
- “刷新索引”会重新扫描两个目录。普通请求使用 30 秒缓存，避免每次操作都扫描近万部视频。
- 播放进度和最近选择会保存在浏览器本地存储中，不写入番剧目录。

## 同步年份和封面

远程清单同步会自动分页读取 MuteFun 的最新番剧列表，按 ID 合并新增条目并更新名称、分类、完结状态、更新备注和封面地址。新条目会补详情和封面；同步失败不会覆盖原清单。默认每 6 小时执行一次，查看页可以手动触发同步。同步只更新本地清单，不会自动下载视频。

当前已有的目录快照没有保存 `vod_year`，因此首次使用筛选页前运行一次：

```powershell
cd limefun
python -m limefun.sync_catalog --workers 8
```

这个命令会：

1. 从详情接口批量补全 2121 部番剧的 `vod_year`。
2. 将 `vod_pic` 下载到 `limefun\covers`，按番剧 ID 缓存。
3. 原子更新 `mutefun_catalog_full.json`，中断时不会破坏原清单。

已有年份和封面会复用；失败项会写入 `catalog_sync_errors.txt`，可以再次运行重试。运行期间需要网络，完成后查看/搜索页只读取本地清单和封面。

## 文件服务

服务端只开放两个固定目录中的视频文件，并对路径做目录穿越校验。视频响应支持 HTTP `Range`，浏览器可以拖动进度条、从中间开始播放；服务端不会把视频一次性读入内存。

支持的扩展名：`.mp4`、`.mkv`、`.webm`、`.m4v`、`.avi`、`.mov`。

索引规则是：顶层目录作为系列名，系列下包含视频的目录作为季 / 子目录；没有子目录时显示为“本目录”。集数按“第 N 集”排序，OVA、SP、剧场版等无法解析集数的文件排在后面。

## 注意事项

- 服务器默认只监听 `127.0.0.1`，同一台电脑上的浏览器可以访问，局域网其他设备不能访问。
- 要让手机、电视或其他电脑访问，可显式监听局域网地址，例如 `--host 0.0.0.0`，同时需要配置 Windows 防火墙；这会扩大媒体文件的可访问范围，应谨慎使用。
- 播放器只读索引和视频，不会移动、重命名或删除任何番剧文件。
- 封面同步只写入 `limefun\covers` 和本地清单，不会修改视频库。
- 浏览器是否能播放某种编码取决于浏览器本身；MP4/H.264 兼容性通常最好，MKV 的支持因浏览器而异。
